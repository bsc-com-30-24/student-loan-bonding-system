# Student Loan Bonding System (Backend)

A centralized, role-based REST API platform that digitizes the bonding lifecycle for
loan-approved students: document submission, verification, agreement generation,
digital signing, storage, status tracking, and compliance monitoring.

> Loan **applications and approvals** are out of scope — handled by an existing system.
> This system begins where approval ends.

## Tech Stack
- **Python + Django REST Framework** — REST API
- **PostgreSQL** — database
- **Docker** — containerized deployment
- **JWT** — authentication
- **Swagger/OpenAPI** — auto-generated API documentation
